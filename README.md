# Сайт Елены Рендаревской

Минималистичное независимое медиа и архив длинных текстов. Сайт полностью статический: статьи хранятся в Markdown, база данных и CMS не нужны.

## 1. Запуск локально

Нужен Node.js 20 или новее.

```bash
npm run dev
```

Откройте `http://localhost:4173`. Команда сначала собирает сайт в папку `dist`, затем запускает локальный сервер. После изменения файлов перезапустите команду.

Проверить финальную сборку без сервера:

```bash
npm test
```

## 2. Как добавить статью

1. Скопируйте любую статью из `content/articles/` и переименуйте файл латиницей.
2. Заполните front matter в начале файла.
3. Напишите текст ниже разделителя `---` обычным Markdown.
4. Поставьте `draft: false`, когда материал готов к публикации.

Обязательные поля:

```yaml
---
title: "Заголовок"
description: "Короткое описание для архива, поиска и Telegram"
date: "2026-08-15"
category: "стратегия"
slug: "zagolovok-latinicey"
draft: false
image: "/og/editorial.png"
---
```

Доступные категории перечислены в `src/site.mjs`. Черновики (`draft: true`) в сайт, RSS и sitemap не попадают.

## 3. Как изменить страницу «Обо мне»

Отредактируйте `content/pages/about.md`. Имя, подпись, адрес сайта и список тем находятся в `src/site.mjs`.

## 4. Как опубликовать изменения

```bash
git add .
git commit -m "Добавить новую статью"
git push
```

Workflow `.github/workflows/pages.yml` соберёт сайт и опубликует папку `dist` через GitHub Pages.

В репозитории на GitHub один раз откройте **Settings → Pages** и в разделе **Build and deployment → Source** выберите **GitHub Actions**. После этого каждый push в ветку `main` будет обновлять сайт.

По умолчанию проект публикуется по адресу `https://rendarevska-ship-it.github.io/-elena-site/`. Workflow автоматически задаёт правильный путь проекта, canonical URL, sitemap, RSS и ссылки на ресурсы.

## 5. Как подключить собственный домен позже

1. Добавьте домен в **Settings → Pages → Custom domain**.
2. Настройте DNS по инструкции GitHub Pages.
3. В `.github/workflows/pages.yml` замените `SITE_URL` на адрес домена и установите `BASE_PATH` в пустую строку.
4. При желании добавьте файл `public/CNAME` с доменом без `https://`.

Важно: адрес `rendarevska.github.io` является GitHub Pages-адресом аккаунта `rendarevska`. Чтобы публиковаться именно там, репозиторий должен находиться в этом аккаунте и называться `rendarevska.github.io`. Текущий репозиторий принадлежит аккаунту `rendarevska-ship-it`, поэтому его стандартный Pages-адрес другой.

## Структура

```text
content/
  articles/           # статьи в Markdown
  pages/about.md      # текст страницы «Обо мне»
public/               # изображения и другие статические файлы
scripts/
  build.mjs           # генератор сайта
  serve.mjs           # локальный сервер
src/
  site.mjs            # настройки, шаблоны и Markdown-рендерер
  styles.css          # весь дизайн
tests/
  site.test.mjs       # базовая проверка результата
```

Проект намеренно не использует CMS, фреймворк и сторонние зависимости. Это делает сборку быстрой, а дальнейшую работу с сайтом — простой.
